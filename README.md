# Mainframe.beta
Mainframe experiência web imersiva e de alta performance, desenvolvida para explorar a intersecção entre modernidade e Inteligência Artificial. Design: Construído com o auxílio de Google AI, Recursos Visuais: Contém elementos visuais gerados por **Gemini** e animações dinâmicas de alta fluidez produzidas com **Kling**.
